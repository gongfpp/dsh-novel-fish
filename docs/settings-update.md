# 0.1.1 设置改进（本地分支，尚未发布）

## 当前入口与流程

左下角头像 → 设置 → 通用设置 → 小说摸鱼。插件详情中的“包含的组件”只是 DSH 展示本包的 Host 组件，不是旧版本依赖；新版不要求先装旧版。

1. 打开一个真实聊天，若思考步骤在“工作过程／已完成”分组里，先展开该分组，让步骤出现在页面。
2. 在设置里导入 EPUB / TXT / MD 文件，用书籍下拉选择当前书。
3. 在“阅读位置（真实思考步骤）”下拉中直接选一个位置即添加，不再进入点选模式，也不用为选择而关闭弹窗。列表为空或聊天更新后可点击“刷新步骤列表”。
4. 图标、主标题、补充文字默认使用下拉预设。只有明确选择“自定义…”才出现输入框，已有自定义值保留。
5. 关闭设置后，主动展开选中的真实思考步骤即可阅读。

## 本轮变化

- 删除粘贴文本入口、设置回调和 store 粘贴导入 API；已有书籍不被删除。
- 删除跨弹窗点选提示和 picking 临时状态；目标候选在宿主适配模块中按真实会话与节点去重。
- 书籍选择改为下拉；显示选中书籍的已读段数、总段数、百分比和“自动记忆进度”，可删除当前选中书籍。
- 常用图标和标题无需打字；保留可选自定义，仍符合原需求的显示自定义能力。
- 修复独立审查发现的自定义输入异步落盘回跳风险；输入使用原生即时值，保存失败有提示。从自定义切换预设失败时保持原模式，不出现无效下拉值。

## 阅读进度的准确含义

进度按每本书持久化，是**下一次首次主动展开要读取的分段位置**。某个目标步骤在本页第一次成功加载一段后，计数推进一次；并不检测用户是否真的读完，也不是段内滚动位置。

同一页面重复展开 A 使用缓存，不再推进；首次展开其他目标 B 读取下一段。缓存跨思考组件重新挂载保留，但刷新页面后清空，之后从书籍保存进度继续。切换书籍清空临时片段，各书进度互不覆盖。没有永久的步骤到小说片段映射。初始化、目标列表读取、设置选择、重渲染和自动展开都不消费正文。

## 尚有限制

- 下拉仅列出当前页面已经挂载的真实思考步骤；不搜索尚未加载的全部历史，也不会为列出候选偷偷展开分组。
- “已读”是成功加载的段数，不是实际阅读确认或书页位置；书末停止，不自动循环。
- 标题图标仍使用集中在小模块的 DSH 原生 DOM 窄适配，仅验证 DSH Web `0.2.1-rc.2`；Desktop、其他宿主版本和其他浏览器尚未验证。
- 保留 EPUB / TXT / MD 文件导入；粘贴移除是本轮明确调整，取代最初需求中的粘贴入口。没有新增独立阅读页、在线书源、目录或排版工具栏。
- GitHub Release 和市场仍是 0.1.0；本分支 0.1.1 未发布，不会自动更新已安装的日常插件。
- 连续中英文字插入已实测，但没有验证操作系统原生中文输入法的完整组合候选流程；配额耗尽、断电恢复与多标签同步仍未实测。
