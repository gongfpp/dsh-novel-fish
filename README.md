# DSH 小说摸鱼

在**真实聊天的原生思考区域**中阅读本地小说：选择“思考”类型后，主动展开时保留原始思考，在正文末尾追加一段小说。重复展开不跳段，另一处首次展开才继续。小说不写入会话、不发送给模型。

适配 **DSH Web 0.2.1-rc.2**。没有独立阅读页、假会话、工作区入口或阅读工具栏。

## 当前分支状态

本分支为 **0.1.2 本地改进版，尚未发布到市场或 GitHub Release**：由“选择具体步骤”改为“选择原生区域类型”，小说追加在真实思考末尾。当前只支持“思考（Thinking）”类型，不假装支持其他类型。已发布的市场索引和下方公开安装地址仍指向 0.1.0，其交互不同。

本地构建和安装（在项目根目录）：

```sh
pnpm verify
pnpm pack --pack-destination dist
dsh plugin --profile web add ./dist/gongfpp-dsh-novel-fish-0.1.2.tgz
```

## 开始读（本分支 0.1.2）

1. 在 **插件** 页启用 **小说摸鱼**，进入 **左下角头像 → 设置 → 通用设置 → 小说摸鱼**。不依赖旧版本；不要同时启用两个接管思考的阅读插件。
2. 导入 `.epub`、`.txt` 或 `.md`，用“当前书籍”下拉选择一本书。旁边显示自动保存的分段进度，并可删除选中书籍。不提供粘贴文本入口。
3. 在“阅读区域类型”中选择 **思考（Thinking）**。适用于任意会话中的该类型，无需选择具体轮次、步骤或刷新位置列表。
4. 图标、主标题、补充文字使用下拉预设；只有选择“自定义…”时才出现文本框。空主标题跟随 DSH 的“思考”。
5. 关闭设置，主动展开原生思考区域。原始思考保持在上方，小说显示在末尾；其他工具日志和模型回答不受影响。已经完成的历史思考同样可用。

自动展开或已恢复展开的思考会保留原文，但不读取小说；需要先收起，再主动展开。设置页只管理书籍和显示，不是阅读入口。

## 安装已发布的 0.1.0（旧交互）

已有可运行的 DSH Web `0.2.1-rc.2` 后，在终端安装固定版本：

```sh
dsh plugin --profile web add github:gongfpp/dsh-novel-fish#v0.1.0
```

仓库的发布版本已包含浏览器构建产物，无需先安装 Node 开发依赖。也可从 [v0.1.0 发布页](https://github.com/gongfpp/dsh-novel-fish/releases/tag/v0.1.0) 下载 `gongfpp-dsh-novel-fish-0.1.0.tgz`：

```sh
dsh plugin --profile web add ./gongfpp-dsh-novel-fish-0.1.0.tgz
```

`web` 是 DSH profile 名称；使用其他 profile 时替换它。安装后刷新现有 DSH 页面；若更换版本仍未加载新代码，重启原来的 `dsh web`，不要另开一个服务器。旧发布的下载与验证范围见 [发布记录](docs/release.md)。

### DSH 自定义插件市场

DSH 当前没有默认的统一第三方插件目录。本项目提供符合官方格式的**自建索引源**，不代表官方审核或推荐：

```text
https://raw.githubusercontent.com/gongfpp/dsh-novel-fish/main/index.json
```

在「发现」页添加索引后安装 **小说摸鱼**。若没有「发现」页，先启用实验性功能中的「自定义插件市场」。**索引仍是已发布的 0.1.0，不包含本分支的类型选择与追加交互**。完整说明见 [市场接入说明](docs/marketplace.md)。

**先停用其他接管思考渲染的阅读插件。** 不依赖旧插件，也不支持两个阅读插件叠加运行。

## 续读规则

- 当前页面首次主动展开思考 A：读取并成功保存进度后，在真实思考末尾追加一段。收起再展开 A 仍用缓存。
- 首次主动展开另一处思考 B：读取下一段。缓存跨组件重挂载保留，不依赖模型是否正在运行。
- 自动恢复展开、加载历史、流式更新和模型结束不加载小说，不覆盖真实思考。
- 刷新后缓存清空；再次主动展开旧 A，从这本书保存的进度继续，不恢复旧片段。
- 切书清空临时缓存，各书分别保存进度；读取失败不推进，书末停止、不循环。
- 初次加载书库失败时禁止覆盖未知的已存数据，并明确报错。

## 文件与本地数据

EPUB 使用 **epubjs 的 Container、Packaging、Navigation 解析器**解析容器、OPF 和导航，按 linear spine 顺序读取 XHTML。ZIP 与 XML 读取失败直接报错。只抽取正文，不执行脚本、不加载书内图片或外部资源，不复刻原书排版。

TXT/MD 保留基本段落、章节；默认每段约 600 个 Unicode 字符，优先在段落/句子边界结束。导入时解析一次，聊天每次只读取一个已经分好的段落。EPUB 累计解压读取上限为 128 MiB；整本导入需要本地内存，极大文件可能受浏览器资源限制。

书籍、段落、设置和每本书的进度存在当前浏览器、当前站点的 IndexedDB。设置保存区域**类型**，不保存会话／步骤位置列表或小说绑定；片段缓存只在当前页面插件实例内。不同浏览器/站点不共享，不提供多标签同步。升级本插件时保留原书库和进度，清理站点数据则会删除书库。只导入你有权使用的内容。

## 兼容与历史验收

原生正文插槽不提供标题/图标接口。本插件采用对具体 DSH DOM 标记的窄适配，停用即移除本地覆盖；正文仍使用 DSH 的真实思考渲染器，小说只追加在其后。不替换聊天根节点，不修改 DSH 安装文件。版本变化需重新验收，不能把设置预览当作实际效果。

本分支 0.1.2 已通过 46 项自动测试，以及真实 DSH 中的原文末尾追加、A/B 缓存续读、刷新和关闭阅读验收；本机 `web` profile 已安装，日常窗口刷新后加载新客户端。详见 [0.1.2 实测与截图](docs/type-append-update.md) 和 [宿主适配说明](docs/host-adapter.md)。

[历史验收记录](docs/acceptance.md) 与 [0.1.1 设置改进](docs/settings-update.md) 保留各自版本的验证范围，不替代本轮运行证据。

## 开发

Node.js 24.19.0、pnpm 12.11.2 为此次构建环境：

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm verify
pnpm pack
```

安装不批准依赖脚本，构建使用 esbuild 平台二进制。运行依赖打入客户端产物，普通用户安装压缩包无需运行开发脚本。

- [chat-adapter.js](src/chat-adapter.js)：唯一 DSH 接入模块。
- [store.js](src/store.js) / [persistence.js](src/persistence.js)：页面缓存、串行读写及本地持久化。
- [segments.js](src/segments.js) / [epub.js](src/epub.js)：导入解析和统一分段。
- [settings.js](src/settings.js)：最小设置。
