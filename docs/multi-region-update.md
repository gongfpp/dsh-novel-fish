# 0.1.4：审计修复与多区域追加

本记录只描述本地 0.1.4 候选版，不代表 GitHub Release 或市场索引已经更新。原有 0.1.0–0.1.3 验收记录属于各自版本，不能替代本轮证据。

## 已实施

1. **小说纯文本**：思考原文仍由 DSH 原生 Factory 渲染，小说改用 React 文本节点；工具中的小说使用 `textContent`。括号、美元金额、邮箱、网址、缩进和类似 Markdown 的行都不再经过数学、自动链接或 Markdown 解析器。不开启 HTML。
2. **关闭与取消类型的竞态**：设置意图同步使未完成读取失效，执行和保存边界重新校验。已经成功缓存的内容不丢弃；设置保存失败也不复活旧读取。宿主待执行帧还会核对意图身份和代次，关后重开、取消后重选、切书后切回均不能复活旧点击。
3. **有界 EPUB 解压**：仅解压容器、OPF、导航及线性正文；不做会提前解压全包的 CRC 检查。分块累计数据在收集前扣除 128 MiB 预算，实际使用项仍增量校验 CRC。采用 `crc-32`，避免 JSZip 深层模块意外引入 Node `stream`、导致浏览器构建失败。128 MiB 是累计解压字节限制，不是峰值堆内存承诺；拼接、解码、XML DOM 另占内存。
4. **明确编码处理**：TXT/MD 支持严格 UTF-8、UTF-8 BOM、UTF-16LE/BE BOM；EPUB XML 另识别 UTF-16 字节标志和相符声明。未知编码、错误编码或不一致声明明确失败，不乱码入库。GBK 当前不自动转码，请先另存为 UTF-8。
5. **XHTML 命名空间**：支持默认、带前缀的 XHTML namespace；保留无 `xmlns` 章节的回退。
6. **正文边界**：块元素维持段落边界，行内元素连贯拼接，隐藏内容和脚本仍被过滤。
7. **章节可见**：正文上方显示“小说 · 章节名”，没有目录或章节导航工具。

## 阅读区域多选

设置在 **左下角头像 → 设置 → 通用设置 → 小说摸鱼**。原来单选的类型改为下拉多选，可“全选 / 全不选”以下五类；不是指定某个会话或某一轮：

| 设置项 | 当前实际定位依据 |
| --- | --- |
| 思考 | `assistant-step` 内的 `data-variant="think"` |
| 工具调用 | 同一 `data-chat-call-id` 下其他原生 `data-tool` 卡片 |
| 打开文件 | `data-tool` 为 `read` / `read_image` |
| 运行命令 | `data-variant="bash"`；兼容当前专用 `data-sample="bash"` 行 |
| 文件搜索 | `data-tool` 为 `grep` / `glob` |

五类不重叠：“工具调用”是其他工具，不会再给同一条命令或文件读取追加第二份。类型全部不选时不读取。只附加在已经存在、可展开的原生区域；没有原生展开控件的卡片不会被改造成阅读区。系统提示、上下文注入、压缩记录和整个过程分组不是本轮新增目标。

**原文、工具输入输出和控件均保留。** 上方是原内容，下方是可见横线、小说/章节标记和一段纯文本；图标、箭头、悬停和折叠事件仍属于 DSH。工具区域没有公开正文末尾插槽，因此只在已定位的原生卡片末尾添加本插件自有节点；关闭、收起或卸载会移除它，不重写工具 renderer。

## EPUB 图片

**不显示书内图片。** 当前只解析文字，不执行脚本、不加载书内或远端图片，也不复刻排版。扫描版/纯图片 EPUB 没有可读文字时会报无正文；本次没有添加图文阅读器。

## 本轮验证

- `pnpm verify`：浏览器构建成功，**92 项通过、0 失败、0 跳过**。
- 覆盖七项审计回归、五类区域独立定位与稳定缓存键、原工具节点保持、明显分隔线/章节、普通文本逐字保留、自动展开不读取、帧内取消不复活、失败不推进、切书/关闭/类型取消、书末停止。

## 手工补验

在已有真实会话导入含 A/B/C 的测试书；勾选全部五类：

1. 主动展开思考或有原生控件的工具行 A：原文/输入输出在上，横线和章节/小说在下；检查文件链接、复制等原生控件仍正常。
2. A 收起再展开进度不变，首次展开 B 才继续；快速重复点击不跳段。
3. 自动展开、切会话、历史加载、流式更新、模型结束不扣段。刷新后主动展开从保存进度继续。
4. 读取未完成时关闭再开启、取消类型再勾选、切书再切回，均不能把旧点击恢复成新读取。
5. 分别单选五类，其他四类不追加；全不选及关闭阅读后恢复原生显示。键盘 Enter/空格、悬停箭头和原生文字选择需在可信输入下补验。
